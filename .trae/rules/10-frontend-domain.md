# 10 Frontend Domain

适用方式：默认加载

这个仓库的当前主领域是前端工作流，不是通用全栈规则库。

默认前端方法论：
- 先业务与输入，再页面结构，再视觉与布局，再代码实现，再审查与沉淀。
- 没有原型时，优先从接口结构和业务语义推导页面骨架、信息层级和状态补全。
- 有已确认设计时，优先基于现有组件体系和前端规范快速落地代码。
- 页面实现必须关注边界状态：空态、加载态、错误态、权限态、禁用态。
- 组件复用优先于临时拼装；页面级容器决策与子组件内容实现要分离。
- 实现结果如果稳定，应继续抽成组件、页面模板、模式资产或标准候选。

边界：
- 不把当前前端领域规则直接提升为全局 User Rule。
- 不把公司项目的目录和依赖限制直接当作所有项目的通用规则。
