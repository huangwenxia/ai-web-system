# 页面审查优先级检查清单

本文件补充 `page-review-skill` 的问题排序口径，避免输出一堆平级建议。

## 先判页面主任务
- 页面是否存在唯一明确的主任务
- 首屏是否优先服务主任务，而不是把低价值信息顶到最前
- 主操作是否在第一扫描路径内

## 严重度排序建议
优先按以下顺序判断：
1. 阻断主任务完成的问题
2. 明显误导用户理解的问题
3. 高频路径中的结构或交互问题
4. 视觉层级、对齐、节奏的系统性问题
5. 局部样式、轻微间距、弱提示等观察项

## 必须优先指出的问题类型
- 页面主任务不清
- 主操作难找或被次要内容打断
- Loading / Empty / Error / Permission / Disabled 状态缺失
- 结构重复表达，导致理解成本明显升高
- 视觉中心错误，弱信息压过主信息
- 可交互元素与纯展示元素反馈混乱

## 可后置的问题类型
- 不影响理解和完成任务的轻微 1px 级问题
- 个别弱提示语气不统一
- 不影响主链路的局部留白微调

## 输出排序要求
- 每条问题至少标记为：立即修 / 建议排期 / 观察项
- 每条问题必须包含：表现、影响、修正方向
- 不把十几个低价值小问题排在真正结构问题前面
