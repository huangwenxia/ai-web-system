# 布局与视觉节奏检查清单

本文件补充 `page-design-skill` 在页面设计收敛阶段的检查项。

## 布局骨架检查
- 页面类型是否明确
- 页面宽度、分栏方式是否合理
- 区块顺序是否符合主任务优先级
- 卡片拆分是否降低认知负担

## 信息节奏检查
- 首屏是否先展示最重要信息
- 第二层信息是否被正确分组
- 操作是否贴近目标对象

## 视觉层级检查
- 标题层级是否稳定
- 主次数据是否明确
- 标签、说明文本、按钮的权重是否合理
- 留白与区块密度是否均衡

## 状态表达检查
- 空态位置是否明确
- 加载态是否可预期
- 错误态是否有承接位置
- 禁用态 / 无权限态是否可解释
