# 产品级审查检查清单

本文件补充 `product-review-skill` 在 A-0 产品级审查主链中的检查项。

## 任务识别检查
- 是否确认任务属于产品级审查与持续优化
- 是否排除了“新增开发”或“根因修复尚未完成的 bug 任务”
- 是否判断清楚当前更适合 `structure_review`、`visual_review`、`ux_review` 还是 `mixed_review`

## 上下文归一化检查
- 是否明确目标页面、组件、模块或链路
- 是否明确主任务、目标用户或核心目标
- 是否明确重点区域和项目约束

## 结构检查
- 主任务入口是否清楚
- 信息是否按业务对象和任务分层
- 区块职责是否清楚
- 组件结构是否存在职责越界

## 视觉检查
- 层级、节奏、留白和对齐是否稳定
- 主视觉焦点是否明确
- 状态表达是否清楚
- 是否存在明显密度失衡或 1px 级可见问题

## UX 检查
- 主路径是否顺畅
- 关键动作是否贴近上下文
- 反馈机制是否充分
- 异常恢复与边界状态是否完整

## 汇总检查
- 是否按严重度而不是按审查学科堆列表
- 是否区分结构 / 视觉 / 体验 / 实现问题
- 是否明确哪些值得立即修，哪些可后续处理
- 是否判断是否需要进入实现修正流

## 输出前检查
- 是否说明了审查模式与子 skill 链路
- 是否给出了可执行修正方向
- 是否判断了是否值得回写
- 是否检查了主 skill 或子 skill 是否需要同步升级
