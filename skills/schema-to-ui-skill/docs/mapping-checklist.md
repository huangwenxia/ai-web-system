# 字段映射与页面骨架检查清单

本文件补充 `schema-to-ui-skill` 在字段映射阶段的检查项。

## 接收参数检查
- 是否至少拿到了 `schema / entity / goal` 其中之一
- 如果用户给的是示例数据，是否已经先还原字段语义，而不是把示例值当字段定义
- 如果用户给的是接口文档，是否已区分请求字段、响应字段和筛选字段

## 输入前检查
- 是否已拿到接口结构、字段说明或业务实体说明
- 是否已明确页面目标或用户目标
- 是否存在关键业务语义缺失，需要先列待确认项

## 字段分类检查
- 字段是否按业务对象分组，而不是按接口顺序平铺
- 是否区分主信息、辅助信息、状态信息、操作信息
- 是否识别出可形成区块的数据集合

## 页面类型判断检查
- 当前更像列表页、详情页、表单页、弹窗页还是工作台
- 页面类型判断是否与用户目标一致
- 是否存在需要拆分多个页面或多个中间区块的情况

## 展示方式检查
- 主信息是否进入标题区、摘要区或首屏核心区
- 状态、布尔、枚举是否使用了显式状态表达，而不是埋在文本里
- 列表项、关联对象、日志记录是否需要独立区块承接
- 长文本、富文本、代码、图片、图表是否与普通文本区分展示

## 边界状态检查
- 空态
- 加载态
- 错误态
- 权限态
- 待确认项

## 输出前检查
- 是否区分高置信度结论与低置信度推断
- 是否明确哪些部分可继续交给实现层
- 是否判断当前结果是否值得回写为案例或模式
