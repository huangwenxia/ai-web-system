# 页面分析优先级检查清单

本文件补充 `page-analysis-skill` 在页面诊断阶段的检查项。

## 接收参数检查
- 是否明确页面主任务或用户目标
- 是否有重点区域或重点问题
- 如果只有截图，是否已说明无法直接判断代码层原因
- 如果只有代码，是否已说明视觉判断会受限

## 输入检查
- 是否已拿到页面截图、描述、代码或问题清单
- 如果输入不足，是否已经明确说明分析依据有限

## 分析维度检查
- 信息架构问题是否已识别
- 视觉层级问题是否已识别
- 交互路径问题是否已识别
- 组件边界问题是否已识别
- 是否先判断了主任务链路，再进入细节问题
- 是否区分了结构性问题和表现层问题

## 优先级检查
- 哪些问题阻断主任务
- 哪些问题增加摩擦
- 哪些问题属于体验欠佳但不阻断

## 输出前检查
- 是否给出了可执行建议
- 是否明确哪些应由实现流处理
- 是否判断是否值得回写为审查口径或案例
