# 目录扫描与 Key 复用细则

本文件补充 `translate-terms-skill` 在 i18n 改造中的扫描、过滤和 key 复用规则。

## 传入目录时的处理方式
当输入是目录而不是单文件时，必须先做扫描，再决定处理范围。

推荐顺序：
1. 扫描目录下所有 `.vue` 文件
2. 搜索尚未被 `t()` / `$t()` 包裹的硬编码中文
3. 过滤掉注释和明显假阳性
4. 输出“哪些文件仍有未翻译中文”的结果摘要
5. 再按用户确认范围逐文件处理

## 扫描重点
- 模板文本节点中的中文
- 属性中的中文
- `<script setup>` 或脚本中的字符串字面量
- `console.error` / `console.warn` / `console.log` 中的中文
- 与变量拼接的中文，如 `{{ value }}核`

## 过滤原则
以下内容不能直接算作“未翻译中文”：
- 已被 `t()` / `$t()` 包裹的文本
- 明显的注释内容
- 与当前任务无关的示例片段

但以下内容仍然要算硬编码：
- 与变量拼接的中文单位
- 模板中直接出现的中文状态词
- 组件属性中的中文 placeholder / label / title

## 先复用 key，再新增 key
对每条待翻译中文，先在 zh-cn locale 文件中搜索完全匹配文本。

### 结果判断
- 找到完全匹配，且 Vue 已正确引用：无需修改
- 找到完全匹配，但 Vue 未引用：复用该 key，只改 Vue 文件
- 未找到：再新增 key

## 不要重复造 key
以下情况都属于不合格新增：
- 同一语义已有现成 key，却再造一个近义新 key
- 仅因当前文件层级不同，就复制一份完全相同文案的 key
- 用随机编号替代语义命名

## 结果展示建议
当目录扫描后存在待处理文件时，建议至少输出：
- 扫描路径
- 命中的文件列表
- 每个文件的大致未翻译行数
- 总文件数与总命中数

当目录下均已完成 i18n 时，应明确说明“无需翻译”，而不是继续假装有修改空间。
