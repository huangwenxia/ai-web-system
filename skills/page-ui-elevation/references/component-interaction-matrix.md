# 空间语义与组件交互映射矩阵 (Component & Motion Matrix)

本矩阵用于在诊断页面时，根据具体场景（专业工作台 vs 营销展示页）精确匹配组件交互与动效模式。

> **🚨 铁律提醒**：严禁无中生有地添加卡片与文案！本矩阵中的所有升级方案必须**原地作用于既有控件（In-place Enhancement）**。严禁将营销页的 BentoGrids 或全屏扫光强塞进工作台！

---

## 一、 专业生产力工作台与工具流（Workstation & Tool Controls）

适用于 AI 创作台、视频制作室、控制台、数据面板、编辑器等高频生产环境。**核心原则：零干扰、沉稳、即时物理反馈、零额外 DOM**。

| 既有控件区域 | 常见平庸现状 (Anti-Patterns) | 原地升维微交互与质感方案 | 物理参数与技术标准 | 预期提升效果 |
|---|---|---|---|---|
| **主输入框 / 创作舱 (Composer / Prompt)** | 扁平暗灰或死白边框，获得焦点瞬间突兀跳变，缺乏悬浮感 | **焦点微流光与 1px 顶部反光边缘**：<br>① 暗色下加入 `border-top: 1px solid rgba(255,255,255,0.12)` 模拟顶光反射；<br>② `:focus-within` 时边框与外发光（`box-shadow`）平滑过渡；<br>③ 悬停时边框微高亮。 | `transition: border-color 220ms var(--ui-ease-out), box-shadow 220ms` | 瞬间摆脱塑料感，获得类似 Linear 的精致悬浮感，不破坏任何既有布局。 |
| **操作按钮与图标工具 (Action & Tool Buttons)** | 点击无反馈，或仅依赖浏览器原生高亮，生硬机械 | **Press 物理微缩放反馈**：<br>按钮在 `:active` 时触发 `transform: scale(0.98)` 或 `scale(0.96)`，松手时基于弹簧弹性恢复，禁用态自动降级。 | 纯 CSS 类名（如 `.ui-press`），时长 160ms，严禁多余包裹 `<span>` | 提供如同机械键盘或实体按键般的扎实确认感。 |
| **参数选择器 / 下拉胶囊 (Pills & Dropdowns)** | 展开与收起生硬瞬间出现，或者生硬淡入 | **微阻尼缩放进场 (Subtle Scale Reveal)**：<br>弹层出现时带 `scale(0.96) -> scale(1)` 与 `opacity 0 -> 1`，微小惯性过冲；选项悬停时底色 160ms 柔和过渡。 | `cubic-bezier(0.16, 1, 0.3, 1)`，时长 180ms，支持 `prefers-reduced-motion` | 消除弹层机械跳跃，操作体验流畅自如。 |
| **成片 / 新增对话揭示 (Media & Message Stream)** | 骨架屏（Skeleton）到真实画面瞬间切换，产生视觉闪烁 | **单次 Reveal 平滑交接**：<br>真实图片/视频加载就绪后，以单次 `opacity: 0 -> 1` 伴随微小 `translateY(4px -> 0)` 呈现，之后完全静止。 | 时长 220ms，严禁循环动画，严禁引起滚动条抖动 | 视觉过渡自然从容，打消等待焦虑。 |
| **列表/分镜拖拽换序 (Storyboard / List Items)** | 拖拽或删除时其他项目瞬间瞬移，破坏空间连续性 | **FLIP 几何形变平滑补间**：<br>元素增删或重新排序时，周围元素沿真实物理轨迹平滑滑动到新位置。 | Vue `<TransitionGroup name="ui-flip">`，时长 220ms | 保持视线焦点连续，专业工具感显著增强。 |
| **复制/状态指示 (State Indicators)** | 仅依靠弹窗（Toast）提示，打断操作视线 | **状态微形变反馈 (In-place Morph)**：<br>点击复制后，图标原地平滑变为 Checkmark（对勾），1.2 秒后平滑复原。 | 单节点状态切换，时长 160ms | 零阻碍就地反馈，极佳的工匠细节。 |

## 二、 商业品牌与营销官网（Marketing & Showcase）

**仅适用于公开营销主页、产品宣传官网或品牌发布页**。在生产力工作台、编辑台中**坚决禁用以下营销套路**！

| 页面空间区域 | 常见平庸现状 | 推荐方案 (仅限营销展示页) | 对应参考站点 | 适用前提与约束 |
|---|---|---|---|---|
| **营销特性矩阵 (Features)** | 3 列死板图标+文字平铺 | **BentoGrids 非对称便当盒** | `bentogrids.com` | **严格限制**：仅当页面本身就是产品宣传页且已有多个独立卖点时使用；**严禁塞入工作台**！ |
| **架构与生态集成** | 枯燥文字描述支持与某系统互通 | **Animated Beams** 动态光束流 | `eldoraui.site` | 仅在展示数据流转与生态连接图时使用。 |
| **客户背书 (Proof)** | 单调排列的小图标 | **Marquee 平滑跑马灯** (悬停暂停) | `eldoraui.site` | 仅在商业官网用于无缝展示大量客户 Logo。 |
| **商业定价 (Pricing)** | 静态三张卡片对比生硬 | 带有平滑弹簧滑块的月/年付切换 | `detail.design` | 仅在公开定价页面使用。 |
| **叙事转折段落** | 传统生硬翻页 | **Particle Scroll** 或平滑视差 | `canvasui.dev` | 仅在品牌故事与发布会页面使用。 |

## 三、 动效实施五大避坑红线 (Anti-Patterns Blacklist)

1. ❌ **严禁“逢页必 Bento”**：BentoGrid 是宣传特性的容器，工作台不需要它。
2. ❌ **严禁常驻扫光与背景微粒**：在生产工具背景放粒子或常驻光斑不仅严重消耗 GPU 资源，还会极度分散注意力。
3. ❌ **严禁表单左右抖动（Shake）**：破坏系统严肃度，使用标准的边框高亮即可。
4. ❌ **严禁整页全屏淡入淡出**：切页时保留即时渲染，避免双容器渲染引起的滚动条跳动。
5. ❌ **严禁破坏原有语义树**：所有动效优先直接施加在现有标签上，禁止为动画随意包无意义的 `div`。
