# 页面骨架检查清单

本文件补充 `prototype-skill` 在原型推导阶段的稳定检查项。

## 业务层检查
- 目标用户是否明确
- 页面主任务是否明确
- 成功标准是否明确
- 关键对象关系是否明确

## 页面骨架检查
- 页面类型是否已经判断清楚
- 首屏目标是否清晰
- 主要区块和辅助区块是否分离
- 操作区、反馈区是否有明确位置

## 状态体系检查
- 空态
- 加载态
- 失败态
- 无权限态
- 未配置态
- 部分完成态

## 输出前检查
- 是否区分了高置信度结论与待确认项
- 是否已经判断下一步更适合 `schema-to-ui`、`page-design` 还是 `frontend-implementer`
