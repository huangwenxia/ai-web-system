Motion 动画库

在 §1.6 Motion Token 之上的「调用层」：4 个标准缓动函数 + 6 个动画 preset class。AI 生成原型时直接 add class 触发，不要自己写 keyframes。

6 个动画 Preset Class

animation

直接 add class 即触发动画，无需写 keyframes 或自定义 transition。所有 preset 已内置 ease 和 duration token。

使用准则 ① 用 class 触发动画（如 <div class="anim-fade-in">），不要自己写 keyframes
② 父元素加 .anim-stagger 让所有子元素错峰淡入（30ms 间隔）
③ Drawer / Toast 用 .anim-slide-in-right / .anim-slide-in-up
④ Modal 用 .anim-scale-in
⑤ 已自动适配 prefers-reduced-motion，无需手动处理

HTML 
<!-- 单元素淡入 -->
<div class="anim-fade-in">...</div>

<!-- Drawer 滑入（从右） -->
<div class="anim-slide-in-right">...</div>

<!-- Modal 缩放出现 -->
<div class="anim-scale-in">...</div>

<!-- 列表行错峰淡入（父加 .anim-stagger） -->
<ul class="anim-stagger">
  <li>Row 1</li>
  <li>Row 2</li>
</ul>

<!-- Vue：动态切换 key 让 v-for 重建触发动画 -->
<ul class="anim-stagger" :key="dataset.id">
  <li v-for="row in rows" :key="row.id">{{ row.name }}</li>
</ul>

场景 → Preset 决策表

guide

遇到这些场景，直接照表选 preset，不要自己思考。

场景用什么时长 + 缓动
列表 / 卡片首次出现.anim-stagger 加在父元素base + ease-out（30ms 错峰）
单个内容卡进入.anim-fade-in 或 .anim-slide-in-upbase + ease-out
Drawer 滑入.anim-slide-in-rightslow + ease-out
Drawer 关闭反向滑出 + ease-inslow + ease-in
Modal 弹出.anim-scale-inbase + ease-out
Toast / Notification.anim-slide-in-upbase + ease-out
Tab 内容切换.anim-fade-in 加在新内容上fast + ease-in-out
CTA 按钮强调transition + --ui-ease-springbase + ease-spring（仅 Hero / 引导卡）
KPI 数字突变JS 数字滚动 + ease-outslow + ease-out
Skeleton → 真实内容真实内容加 .anim-fade-in + Skeleton v-if 立即消失fast + ease-out
红线（§4.3 修订） ① 普通卡片 / 表格行 hover 严禁位移 / scale（保持原规则）
② Hero band 入口卡 / CTA 按钮等"主行动强调"允许 -2px 位移 + ease-spring（修订：高强调区域可以有反馈）
③ 不要在同一元素嵌套多层 anim-* class（fade-in 套 slide-in）
④ prefers-reduced-motion 已自动处理，禁止手动覆盖
