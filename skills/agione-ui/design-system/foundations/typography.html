L1 · Base Spec

字号 / 字重 / 行高属于 L1 视觉系统层，跟 chrome / 颜色 token 一个层级——必须 100% 锁死，AI 没有发挥空间。所有文字元素必须用以下 8 个 class 之一，禁止在 HTML 上手写 font-size / font-weight / line-height / font-family。

关键约束（references/base-spec.md §3） ① 禁止手写 font-size / font-weight / line-height / font-family，必须用 .type-* class
② 颜色与字型解耦：颜色用 var(--*) token 单独设置（如 color: var(--ui-text-muted)），让 caption 也能用 foreground 色，灵活搭配
③ 极少数例外（如 KPI 巨数字 / Hero 营销字）：先升级 §2.2 字型表，加新 .type-* class，禁止现场写
④ 关于自由发挥：字体跟 chrome / 颜色一样是视觉系统的根，无发挥空间。AI 的创新力应该用在"页面布局 + 内容呈现"，不是"该用 14 还是 15 px"
