AGIOne Design System · v1.0

面向同事的可视化原型组件库 + 选型规范

这份文档把 SKILL.md v3.7 里的设计 DNA、组件契约和真实业务原型沉淀的视觉模式， 整合成一个可视化、可复制的单文件参考。每个 token 都有色块/尺寸样例，每个组件都有 Live Preview 和 HTML 代码块—— 你想看什么、抄什么、贴到原型里，三秒搞定。

8 类设计 token 15 个核心组件 4 套页面骨架 支持 Light/Dark · 中/EN
Getting Started

如何使用这份 Design System

三种典型用法，从最快到最系统，按你当前的需求选一种。

① 选型查表
最快
做新页面前先来这里。看一下「页面骨架」选用哪种结构（列表 / 详情 / Overview）， 然后从「容器组件」「原子组件」挑搭配。每块都附 HTML 直接拷走。
② 复制粘贴
最常用
每个组件下方的代码块右上角点 Copy 按钮， 贴进你的原型 HTML 即可。所有代码都使用 var(--*) CSS 变量，跨主题安全。
③ 验收对齐
PM/QA
原型做完，对照本文档的 token 值和组件骨架做"漂移检查"： 颜色是否走变量、间距是否用 scale、Badge 是否在词汇表内。

三个最重要的红线（来自 SKILL.md）

① Chrome（TopBar/Sidebar）必须从 agione-console-shell-sample-v1.html 逐字复制；
② 颜色 / 间距 / 圆角 / 阴影 / 动效 / 字族 / 图标尺寸 / z-index 必须用 var(--*)，禁止硬编码；
③ 所有组件容器必须带 data-component="..." 标记，方便 HTML→Vue 转换工具识别边界。

Design Tokens · 6/8

动效 Motion

3 个时长 token + 1 个标准缓动。hover 只做颜色变化，不做位移 / scale。 150ms 是默认过渡时长，感觉「快但不急」。

下面 3 张卡片用完全相同的效果（背景色 + 边框色变化），只是时长不同。把鼠标悬停到卡片上对比"快 → 中 → 慢"的差异。

Fast · 150ms
--ui-duration-fast
hover / focus / state 变化
默认过渡时长，"快但不急"
Base · 250ms
--ui-duration-base
Tooltip 出现、卡片浮起
中等节奏，强调连续感
Slow · 400ms
--ui-duration-slow
Drawer / Dialog 进出
用于容器进出，不是 hover
缓动函数 Easing
所有动画统一用 --ui-ease-out
--ui-ease-out cubic-bezier(0.4, 0, 0.2, 1)
曲线开头陡（速度快）、结尾平（速度慢）—— 物体"冲出去然后稳稳停下"。所有 hover / tooltip / 卡片浮起 / Drawer 进出统一用此曲线。禁止自定义其他缓动。
linear
ease-out
↑ 两个球同时间到达终点，但 ease-out（紫）开头冲、结尾收，linear（灰）匀速。这就是为什么 ease-out 让界面"感觉更精致"。
动效红线（与 §4.3 一致） ① hover 严禁位移（translateX/Y）和 scale —— 容易让用户以为可拖拽、产生晕动症。
② 只有 Drawer / Dialog 进出这种本身就是位移的容器组件可以用 transform，且必须搭配 --ui-duration-slow。
③ 不要嵌套多层动效（一个元素同时 transition 4+ 个属性），效果会"打架"。

Popconfirm · 行级二次确认

基于 Element Plus <el-popconfirm>。表格行内 / 卡片内的"删除"等危险操作的轻量二次确认，比 Modal 更轻、不打断流。

Popconfirm

overlayEP 2.9

气泡 240px 宽，含警告图标 + 短文案 + 取消/确认两个按钮。影响小、可恢复的危险操作用 Popconfirm；影响大、不可逆的危险操作用 Modal Confirm。

vs Modal Confirm 选型 Popconfirm（轻）：单行删除 / 移除关联 / 撤销待审 / 取消订阅（影响范围 = 1 行 / 1 个对象）
Modal Confirm（重）：禁用整个 License / 删除整个项目 / 不可恢复的批量操作（影响 ≥ 多个用户或不可逆）
