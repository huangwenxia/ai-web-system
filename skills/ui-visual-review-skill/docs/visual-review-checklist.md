# 视觉审查检查清单

本文件补充 `ui-visual-review-skill` 在视觉诊断阶段的检查项。

## 接收参数检查
- 是否明确目标页面、组件或区块
- 是否明确输入类型：截图、录屏、代码还是问题清单
- 是否明确页面主任务或核心用户目标
- 是否有重点区域或重点视觉问题

## 视觉层级检查
- 首屏主视觉焦点是否明确
- 标题、主数据、辅助信息、说明信息是否形成层级
- 是否存在辅助元素比主信息更抢眼的注意力竞争

## 节奏与留白检查
- 区块间距是否稳定
- 卡片内部语义层级间距是否稳定
- 页面是否出现局部过密或过空
- 网格卡片是否存在异常高低和轻重失衡

## 对齐与组件检查
- 标题、按钮、标签、数字、表单项是否形成统一基线
- 同类组件尺寸、权重、样式是否一致
- 是否存在通过魔法数手动“视觉对齐”的痕迹

## 状态表达检查
- 空态、加载态、错误态、禁用态、选中态是否完整
- 状态颜色、图标和强调方式是否与语义一致
- 骨架屏或 loading 占位是否与真实布局匹配

## 输出前检查
- 每个问题是否都说明了表现、影响和修正方向
- 是否区分视觉问题与结构问题
- 是否明确哪些要转交 `page-design`、`page-analysis` 或 `frontend-implementer`
- 是否判断是否值得沉淀为稳定视觉审查口径
