# 任务类型判断矩阵

## 目标

帮助在接到任务时，快速判断它属于哪一类工作，以及默认应该走哪条处理路径。

## 主类型

1. 需求理解 / 业务梳理
2. 页面 / 组件设计
3. 前端实现
4. 审查类任务
5. 原型 / 结构推导
6. 文档 / 规则整理
7. 脚本 / 工具维护

主类型只选一个。

## 快速矩阵

| 典型任务 | 主类型 | 默认工作流 | 是否默认回写 |
| --- | --- | --- | --- |
| 理解接口、整理字段、梳理业务目标 | 需求理解 / 业务梳理 | 分析与结构化整理 | 否 |
| 设计页面结构、区块层级、交互路径 | 页面 / 组件设计 | 方案产出与评审 | 视情况 |
| 根据既有方案落代码 | 前端实现 | 实现与联调 | 否 |
| 做代码审查、视觉审查、UX 审查 | 审查类任务 | 审查与结论输出 | 视情况 |
| 从 schema 推页面、做信息架构草案 | 原型 / 结构推导 | 原型推导 | 视情况 |
| 更新 README、规则说明、治理文档 | 文档 / 规则整理 | 文档维护 | 是 |
| 修脚本、补校验、改同步工具 | 脚本 / 工具维护 | 脚本维护 | 否 |

## 各类型说明

### 1. 需求理解 / 业务梳理

典型任务：

- 拆接口
- 整理字段
- 明确用户目标

默认产物：

- 结构化说明
- 页面目标
- 数据映射草案

### 2. 页面 / 组件设计

典型任务：

- 设计页面骨架
- 拆区块
- 补状态

默认产物：

- 结构方案
- 信息层级
- 状态说明

### 3. 前端实现

典型任务：

- 落 Vue 页面
- 拆子组件
- 对接真实组件库

默认产物：

- 可运行代码
- 注释或使用说明

### 4. 审查类任务

典型任务：

- 代码 review
- 页面审查
- UX 审查

默认产物：

- 风险列表
- 优先级排序
- 修正建议

### 5. 原型 / 结构推导

典型任务：

- schema 到 UI
- 页面信息架构草案
- 低保真原型

默认产物：

- 页面框架
- 区块和字段映射

### 6. 文档 / 规则整理

典型任务：

- 更新总览文档
- 调整规则说明
- 收敛职责边界

默认产物：

- 文档更新
- 规则说明更新

### 7. 脚本 / 工具维护

典型任务：

- 修校验脚本
- 加同步能力
- 收敛命令入口

默认产物：

- 脚本改动
- 使用说明

## 回写原则

只有当结论满足这两个条件时，才默认考虑回写：

1. 它已经在多个任务里稳定成立。
2. 它脱离单个任务后仍然有复用价值。

否则就只保留在当前任务结果里。
