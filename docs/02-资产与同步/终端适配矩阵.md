# 终端适配矩阵

本文档记录各 AI 终端工具对 Commands、Skills、Rules 的支持情况、格式要求和同步策略。

**重要原则**：在通过脚本转换之前，必须查阅各工具的最新官方文档，因为支持情况会频繁变化。

---

## 终端支持概览

| 终端 | Commands | Skills | Rules | 同步脚本 |
|------|----------|--------|-------|----------|
| Claude Code | ✅ `.md` | ❌ | ❌ | `sync-all.mjs` |
| Codex | ❌ | ✅ `.md` | ❌ | `sync-all.mjs` |
| Cursor | ✅ `.md` | ✅ `.md` | ✅ `.mdc` | `sync-all.mjs`, `sync-project-rules.mjs` |
| Roo Code | ✅ `.md` | ❌ | ❌ | `sync-all.mjs` |
| Cline | ✅ | ❌ | ❌ | 需手动配置 |
| Trae-CN | ✅ | ✅ | ✅ `.mdc` | `sync-all.mjs`, `sync-project-rules.mjs` |

**重要**：
- ✅ = 官方确认支持
- ❌ = 官方不支持
- ❓ = 需查阅最新文档确认

## 各终端详细说明

### Claude Code

**官方文档**：[Claude Code Documentation](https://docs.anthropic.com/en/docs/claude-code)

**Commands（Slash Commands）**：
- 格式：`.md` 文件
- 位置：`~/.claude/commands/`
- frontmatter：`name` 和 `description`
- 示例：
```markdown
---
name: my-command
description: What this command does
---
# Command content
```

**Skills**：
- ❌ **不支持**本地 skills
- 仅支持通过 `/skill` 调用内置能力

**Rules**：
- ❌ 不支持 Project Rules (.mdc)
- 通过 `--system-hints` 或项目级配置间接实现

---

### Codex

**官方文档**：[Codex Documentation](https://docs.codex.org)

**Commands**：
- 不支持

**Skills**：
- 格式：`.md` 文件（SKILL.md）
- 位置：`~/.codex/skills/<skill-name>/SKILL.md`
- frontmatter：`name`, `description`, `alwaysApply?`
- 支持子目录（`docs/`, `templates/`）
- **注意**：Codex 有内置 Skill 市场，也可以本地自定义

---

### Cursor

**官方文档**：[Cursor Rules Documentation](https://cursor.com/docs/rules)

**Commands（Slash Commands）**：
- 格式：`.md`
- 位置：`~/.cursor/commands/`
- Cursor 0.4+ 支持

**Skills**：
- 格式：`.md`（SKILL.md）
- 位置：`~/.cursor/skills/<skill-name>/SKILL.md`
- **注意**：不要写入 `~/.cursor/skills-cursor/`，这是内置保留目录

**Project Rules**：
- 格式：`.mdc`（Markdown + YAML frontmatter）
- 位置：`.cursor/rules/` 或 `.cursorrules`
- Project Rules 会自动应用于项目
- 支持 `alwaysApply: true/false` 和 `globs`

**Rules 分层**：
1. User Rule（全局）
2. Project Rules（项目级）

---

### Roo Code

**官方文档**：[Roo Code Documentation](https://roocode.com/docs)

**Commands**：
- 格式：`.md`
- 位置：`~/.roo/commands/`
- 类似于 Claude Code 的 slash commands

**Skills**：
- 支持程度不明确
- 建议查阅官方最新文档

---

### Cline

**官方文档**：[Cline Documentation](https://github.com/cline/cline)

**Commands**：
- 支持 custom commands
- 格式：`.md` 或 `.js`
- 位置：插件配置目录

**Skills**：
- 支持程度不明确
- 建议查阅官方最新文档

---

### Trae-CN

**官方文档**：国内产品，文档可能在 [trae.ai](https://trae.ai)

**兼容性**：
- 兼容 Cursor 格式
- Commands、Skills、Rules 格式与 Cursor 相似

## 同步脚本

### 统一入口：sync-all.mjs

```powershell
node scripts/sync-all.mjs
```

**自动检测**：
- 目标终端是否官方支持对应功能
- 目标目录是否存在
- 仅同步到可用的终端

### 单独同步

| 脚本 | 同步内容 | 目标终端 |
|------|----------|----------|
| `sync-commands-and-skills.mjs` | Commands + Skills | Claude Code, Codex, Cursor, Roo Code, Trae-CN |
| `sync-project-rules.mjs` | Rules (.mdc) | Cursor, Trae-CN |

### 同步策略

```
rules/           -> .cursor/rules/          (Project Rules)
                  -> .trae/rules/           (Project Rules)
commands/        -> ~/.claude/commands/    (Claude Code)
                  -> ~/.cursor/commands/   (Cursor)
                  -> ~/.roo/commands/      (Roo Code)
skills/          -> ~/.codex/skills/       (Codex)
                  -> ~/.cursor/skills/     (Cursor)
```

### 格式转换规则

| 源格式 | 目标格式 | 转换说明 |
|--------|----------|----------|
| `.md` (commands) | `.md` | 直接复制 |
| `.md` (skills) | `.md` (SKILL.md) | 直接复制，保持目录结构 |
| `.mdc` (rules) | `.mdc` | 直接复制（Cursor Project Rules） |

**重要**：不同终端对 frontmatter 字段支持不同，转换时需要：

1. **检查目标终端的 frontmatter 字段**
2. **添加目标终端需要的字段**
3. **移除不支持的字段**
4. **验证转换后的文件格式**

### 同步前检查清单

- [ ] 查阅目标终端最新官方文档
- [ ] 确认支持的文件格式
- [ ] 确认 frontmatter 字段是否兼容
- [ ] 确认目标目录路径
- [ ] 确认编码（UTF-8 无 BOM）
- [ ] 测试同步后的文件是否可用
