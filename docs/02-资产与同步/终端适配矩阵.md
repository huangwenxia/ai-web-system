# 终端适配矩阵

本文档记录 `ai-web-system` 当前实际维护的终端资产、同步目标和清理策略。

重要原则：

- 修改终端支持矩阵前，必须先查阅各工具的最新官方文档。
- 本仓库当前只维护 `skills` 和仓库内 `rules` 投影。
- 历史 `commands` 层已退役，同步脚本只负责清理旧残留，不再投放新 command 文件。
- 外部项目的终端 / 插件目录不再由本仓库注入维护；项目级文件应来自目标仓库自身的 clone / pull。

---

## 当前维护矩阵

| 终端 | skills | rules | 说明 |
| --- | --- | --- | --- |
| Claude Code | yes | no | 同步到 `~/.claude/skills` |
| Codex | yes | no | 同步到 `~/.codex/skills` |
| Cursor | yes | yes | skills 到 `~/.cursor/skills`，rules 到当前仓库 `.cursor/rules` |
| Trae-CN | yes | yes | skills 到 `~/.trae/skills`，rules 到当前仓库 `.trae/rules` |
| Roo Code | no maintained assets | no | 仅清理历史 `~/.roo/commands` 残留 |
| Cline | no maintained assets | no | 仅清理历史 `~/.cline/commands` 残留 |

---

## 技能同步目标

- Claude Code -> `~/.claude/skills/`
- Codex -> `~/.codex/skills/`
- Cursor -> `~/.cursor/skills/`
- Trae-CN -> `~/.trae/skills/`

技能目录保持：

- `<skill-name>/SKILL.md`
- 可选 `docs/`
- 可选 `templates/`
- 可选 `scripts/`

---

## 规则同步目标

- Cursor -> `<repo>/.cursor/rules/`
- Trae-CN -> `<repo>/.trae/rules/`

这里的 `<repo>` 指当前 `ai-web-system` 仓库本身，不再支持把 rules 注入别的项目目录。

---

## 历史 commands 清理

以下目录中的非隐藏旧文件会在同步时被清理：

- `~/.claude/commands/`
- `~/.cursor/commands/`
- `~/.roo/commands/`
- `~/.trae/commands/`
- `~/.cline/commands/`

保留项：

- 隐藏目录
- 系统自带目录
- 其他隐藏项

---

## 同步脚本

### 统一入口：`sync-all.mjs`

```powershell
node scripts/sync-all.mjs
```

默认行为：

- 同步所有当前维护的 `skills`
- 同步当前仓库的 `rules` 投影
- 清理历史全局 `commands` 残留

### 单独同步 skills

```powershell
node scripts/sync-skills.mjs
```

### 单独同步规则投影

```powershell
node scripts/sync-project-rules.mjs
```

---

## 常用参数

```powershell
--terminal=claude-code,cursor
--asset=skills,rules
--plugin=skill
--name=existing-project-feature-skill
--dry-run
--list
```

## 同步前检查清单

- [ ] 查阅目标终端最新官方文档
- [ ] 确认目标终端仍支持当前目录格式
- [ ] 确认目标目录路径
- [ ] 确认编码为 UTF-8
- [ ] 用 `--dry-run` 先看一次计划
