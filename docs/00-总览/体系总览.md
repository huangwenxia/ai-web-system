# 体系总览

## 这套系统是什么

`ai-web-system` 不是单纯的提示词仓库，也不是独立产品代码库。它的目标是把 AI 辅助前端开发里稳定有效的做法拆成可维护的标准、规则、技能协议、示例和脚本。

一句话概括：这是一个本地优先的 AI 前端协作体系。

## 核心目标

1. 提升从输入到页面落地的速度
2. 提升结构、视觉和实现质量的一致性
3. 把稳定结论沉淀成可复用规则，而不是停留在单次对话里

## 当前结构

### 1. 标准层

回答“什么算对，什么算稳定”。

- `standards/`
- `docs/`

### 2. 规则编排层

回答“哪些约束应该在具体工具里默认生效”。

- `rules/`
- `.cursor/`
- `.trae/`

### 3. 协议层

回答“任务如何被调用、如何执行、由谁承接”。

- `skills/`
- `agents/`

### 4. 支撑层

回答“怎么做校验、同步和辅助维护”。

- `scripts/`
- `examples/`

## 当前不再保留的方向

- 不再维护独立 `commands/` 入口层
- 不再从本仓库向外部项目目录注入终端 / 插件资产
- 不再维护独立的可视化工作台或额外预览层

## 这套系统解决什么问题

- 同一类任务每次都从头开始
- 规则只存在于个人经验里，无法复用
- 不同 AI 工具下的默认行为不一致
- 审查结论没有回流到标准和文档

## 推荐理解方式

不要先按目录看，而要先按闭环看：

1. 输入任务
2. 挂载规则
3. 选择 skill / agent 协议
4. 产出方案和代码
5. 做审查
6. 回写稳定结论

## 当前优先级

第一阶段优先保证：

- 标准清晰
- 规则挂载稳定
- 协议边界明确
- 脚本只做必要辅助
- 回写路径清晰
