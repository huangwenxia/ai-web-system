# Cursor 手动调用速查表

如果当前 Cursor slash command 菜单尚未稳定出现，你仍然可以先按下面的“入口约定”来手动调用。

##组件 / 页面实现
- `/frontend-implementer 做一个收益统计卡，先沉淀知识库，不直接同步正式项目`

## 接口到页面骨架
- `/schema-to-ui 根据这个接口结构推导一个 hashrate 概览页草稿`

## 页面问题分析
- `/page-analysis 帮我分析这个页面的信息层级、交互路径和组件结构问题`

##视觉审查
- `/ui-visual-review 帮我审查这版页面视觉层级、卡片节奏和状态完整性`

## 推荐用法
如果 slash 菜单未来生效，你就按真正 slash command 用；
如果暂时不生效，也可以把这类写法当成“你和智能体的命令约定”。

## 一句话
先把命令名固定下来，等 Cursor目录加载机制完全验证清楚后，再把它变成真正的 slash UI入口。
