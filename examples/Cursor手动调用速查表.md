# Cursor 手动调用速查表

如果当前 Cursor slash command 菜单尚未稳定出现，你仍然可以先按下面的“入口约定”来手动调用。

## 新功能开发
- `/existing-project-feature 基于这份已确认原型实现一个 hashrate 概览页`

## 先生成原型再实施
- `/AGIOne-ui 生成模型广场列表页原型，确认后再进入 existing-project-feature`

## 组件 / 页面实现
- `/frontend-implementer 根据这份已确认原型实现收益统计卡`

## 页面审查
- `/page-review 帮我审查这个页面的信息层级、视觉节奏和交互路径问题`

## 修复与优化
- `/existing-project-fix 修复这个筛选切换后列表不刷新的问题`

## 文案与 i18n
- `/translate-terms 统一这个模块的按钮文案和 locale key`

## 推荐用法
如果 slash 菜单未来生效，你就按真正 slash command 用；
如果暂时不生效，也可以把这类写法当成“你和智能体的命令约定”。

## 一句话
入口已经收敛成“原型生成 / 新功能实施 / 修复 / 审查 / 翻译”几条主链，不再保留旧的拆分命令。
