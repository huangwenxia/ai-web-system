# Cursor 手动调用速查表

仓库不再维护独立 slash command 层。需要显式调用时，直接点名 skill 名称，并把任务描述写清楚。

## 新功能开发

- `existing-project-feature-skill：基于这份已确认原型实现一个 hashrate 概览页`

## 先生成原型再实施

- `agione-ui-skill：生成模型广场列表页原型，确认后再进入 existing-project-feature-skill`

## 组件 / 页面实现

- `frontend-implementer-skill：根据这份已确认原型实现收益统计卡`

## 页面审查

- `page-review-skill：帮我审查这个页面的信息层级、视觉节奏和交互路径问题`

## 修复与优化

- `existing-project-fix-skill：修复这个筛选切换后列表不刷新的问题`

## 文案与 i18n

- `translate-terms-skill：统一这个模块的按钮文案和 locale key`

## 一句话

现在的入口收敛成“直接调用对应 skill”，不再保留独立 `commands/` 目录。
