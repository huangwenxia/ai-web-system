# Cursor 配置说明

这里存放 `ai-web-system` 面向 Cursor 的项目规则投影与辅助模板。

## 目录

- `rules/`：从仓库根目录 `rules/` 同步过来的 Cursor Project Rules
- `user-rule.template.md`：建议粘贴到 Cursor User Rule 的全局模板

## 当前 Project Rules

- 既有项目前端开发约束
- bug 修复与优化约束
- Markdown 文档规范
- 回写治理约束

## 原则

1. `rules/` 是维护源，`.cursor/rules/` 是投影。
2. Project Rules 只放当前仓库稳定成立的约束。
3. User Rule 只放跨项目都成立的通用工程行为。
