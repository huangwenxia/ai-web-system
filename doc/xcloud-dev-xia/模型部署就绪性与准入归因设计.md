# 模型部署就绪性与准入归因设计

- 文档状态：从云账号检测架构拆分，独立维护
- 最后更新：2026-08-03
- 适用系统：metis-hashrate
- 云账号配套文档：[云账号检测阶段与统一归因架构设计](./云账号检测阶段与统一归因架构设计.md)

## 1. 文档职责

本文独立负责模型部署上下文、部署准入、真实创建及异步执行错误的归因设计。部署就绪性不属于云账号新增、编辑、列表管理或账号健康检测，不进入 XCloud 后端的 `stageCode`、`checkCode`、`reasonCode`和处理动作枚举。

本文沿用以下部署侧概念作为 Hashrate 自有契约：

```text
stageCode = DEPLOYMENT_ADMISSION
checkCode = DEPLOYMENT_READINESS
```

Hashrate 如需落地这些编码，应在部署域自己的契约和代码中维护，不反向扩张 XCloud 云账号检测模型。

## 2. Owner 与调用边界

部署准入的事实 Owner 是 Hashrate，因为地域、工作空间、模型、制品、规格、配额、容量、网络、服务角色和最终部署参数都来自真实部署上下文。

```text
Hashrate（模型、框架、地域、规格、路由、License、最终部署命令）
    └─ 单向读取 XCloud hyperone-account-api
       （云账号、主体、基础产品访问、最近有效健康结论）
```

边界固定为：

- XCloud 不保存模型部署上下文，不执行部署就绪性检测，不定义部署原因枚举。
- Hashrate 不要求云账号新增、编辑或健康重检返回部署就绪性槽位。
- 已有同步校验继续收敛在真实部署命令中，不新增无上下文的账号侧部署预检接口。
- 真实创建及异步执行错误由 Hashrate 基于结构化证据归因。

## 3. Hashrate 已有同步检查

核验基线：`metis-hashrate` HEAD `adb8e97f140e1579f0dd668381df08bbd00ba793`。

| 检查 | 当前时点 | 代码事实与收敛方向 |
|---|---|---|
| License实例数 | 云端创建前 | `requireCreateAllowed(AI_INFRA, 1)`；保持 Hashrate 所有 |
| 部署模式、主节点、高可用策略必填 | Controller与Service同步 | 统一由Service准入器返回稳定归因，Controller只做参数绑定 |
| 模型存在、框架版本必填及存在 | 本地任务预创建前 | 补齐空框架版本的确定性失败，不能进入异步空指针 |
| 账号存在、账号与云类型一致 | 推荐确认与规格检查时 | 普通创建和推荐确认共用检查，并读取XCloud最近有效健康结论 |
| 框架类型、云类型、地域一致 | `confirmDeploy`同步 | 传统`create`路径也应执行 |
| 高可用每条路由存在同云类型租户账号 | `confirmDeploy`同步 | 异步激活不能以“找不到就跳过”继续部署 |
| 云规格实时可用 | 当前在本地任务预创建后、云端创建前 | 阿里EAS已有真实覆盖；AWS、Google、华为默认放行不能声称已实时检查 |

## 4. 通用部署就绪归因项

以下原因均属于 `DEPLOYMENT_ADMISSION + DEPLOYMENT_READINESS`，不得出现在云账号配置或账号健康结果中。

| `reasonCode` | 提交前同步 | 最早可检阶段 | 只读无副作用探针 | 用户处理方向 |
|---|---|---|---|---|
| `DEPLOYMENT_PERMISSION_MISSING` | 是 | 账号、地域、产品和目标操作确定后 | 权限测试API；无测试API时使用最小只读List/Get | 查看并补齐部署所需权限 |
| `DEPLOYMENT_REGION_UNAVAILABLE` | 是 | provider、产品和region确定后 | 官方Regions/Locations或产品地域目录 | 选择支持的地域 |
| `DEPLOYMENT_WORKSPACE_UNAVAILABLE` | 是 | workspace/project已选择 | 按ID Get/List精确匹配 | 选择或配置有效工作空间 |
| `DEPLOYMENT_MODEL_UNAVAILABLE` | 是 | model、frameworkVersion、region确定后 | 本地权威查询及云端Models Get/List | 选择可用模型或版本 |
| `DEPLOYMENT_ARTIFACT_ACCESS_DENIED` | 部分 | artifact URI和执行角色确定后 | Head/Get metadata、镜像Describe/BatchGet | 修复制品与执行角色权限 |
| `DEPLOYMENT_SPECIFICATION_UNAVAILABLE` | 是 | region、框架、spec、加速器确定后 | 规格或机器类型目录 | 更换规格或地域 |
| `DEPLOYMENT_QUOTA_INSUFFICIENT` | 部分 | 资源需求可计算后 | 配额Get/List | 申请配额或减少实例数 |
| `DEPLOYMENT_CAPACITY_UNAVAILABLE` | 部分 | region、zone、spec、count确定后 | 官方实时库存或可用性查询 | 重试或更换地域、规格 |
| `DEPLOYMENT_NETWORK_UNAVAILABLE` | 部分 | 网络输入齐全后 | VPC、子网、安全组、Endpoint只读查询 | 修正网络配置 |
| `DEPLOYMENT_SERVICE_ROLE_MISSING` | 是 | 云商和角色名确定后 | IAM Role或Agency Get | 配置服务角色 |
| `DEPLOYMENT_SERVICE_ROLE_INVALID` | 部分 | 角色存在后 | 角色、信任策略、附加权限查询 | 修复角色信任与权限 |
| `DEPLOYMENT_RESOURCE_CONFLICT` | 是 | 最终云端资源名确定后 | 按名称Describe/List | 改名或选择复用 |
| `DEPLOYMENT_CONFIGURATION_INVALID` | 是 | 表单字段齐全后 | 本地契约、组合矩阵及明确无副作用的Validate API | 定位字段并修改配置 |
| `DEPLOYMENT_READINESS_ERROR_UNCLASSIFIED` | 否 | 真实业务失败发生时 | 不主动探测，只承载安全回落 | 展示安全错误摘要，不猜测具体原因 |

规格不可用表示目标范围不支持该规格；容量不足表示规格受支持但当前暂时无容量。两者的证据和处理操作必须分开。

## 5. 云商探针与证据方向

| provider | 归因方向 | `probeApi` / `providerOperation` | 证据边界 |
|---|---|---|---|
| 阿里云/阿里金融云 | 权限、地域、工作空间、规格、容量 | PAI `ListWorkspaces`、EAS `ListServices`、ECS `DescribeRegions`、EAS `DescribeMachineSpec` | 区分规格不支持与实时无库存；金融云使用金融云地域集合 |
| AWS | 权限、地域、规格、配额、服务角色、制品 | IAM `SimulatePrincipalPolicy`、SageMaker只读List/Describe、Service Quotas、IAM GetRole、S3 HeadObject、ECR BatchGetImage | 权限模拟自身可能受限；当前身份可读不等于执行角色可读 |
| Google Cloud | 权限、地域、模型、规格、配额 | `testIamPermissions`、Service Usage、Vertex Locations/Models、Cloud Quotas | Location存在不等于指定模型或机器类型可用；配额维度无法对齐时不精确归因 |
| 华为云 | 权限、工作空间、服务角色、规格 | ModelArts在线服务List/Get、授权管理、Workspace、IAM Agency | 全局错误码不能脱离实际接口直接匹配，需验证当前SDK/API响应 |

成熟度边界：官方文档确认或代码可观察不等于生产已验证。没有受控真实账号证据时，只能声明 `OFFICIALLY_DOCUMENTED`、`CODE_REPRODUCED`或`PRODUCTION_VALIDATION_REQUIRED`，不能声明 `OPERATIONALLY_OBSERVED`。

## 6. 不能可靠前置的项目

| 项目 | 为什么不能可靠前置 | 运行时处理 |
|---|---|---|
| 查询后发生的配额或库存竞态 | 预检与Create之间状态可变 | Create结构化错误继续归因，保留观察时点并支持重试或换规格 |
| 云商最终一致性 | 新建角色、授权、模型、镜像或对象可能尚未传播 | 提示等待并重试，保留安全的requestId和结构化状态 |
| 托管服务代入角色读取制品 | 当前凭证读取成功不等于执行身份读取成功 | 依据Create或异步状态中的明确角色、制品错误归因 |
| 容器启动、模型解包、健康检查、端口或命令错误 | 需要真实运行环境 | 归真实创建后的异步错误；可本地确定的字段契约才前置 |
| VPC路由、DNS、NAT、服务端点端到端连通 | 只读资源存在性不足以证明数据面可达 | 创建后健康或事件观察；超时作为技术错误，不猜测业务原因 |
| 云商内部故障、限流、5xx | 用户无法通过修改配置确定解决 | 返回实际执行项的技术错误，不映射业务原因 |

## 7. 处理操作目录

| `resolutionCode` | 中文操作 |
|---|---|
| `VIEW_REQUIRED_PERMISSIONS` | 查看所需权限 |
| `SELECT_SUPPORTED_REGION` | 选择支持的地域 |
| `CONFIGURE_WORKSPACE` | 配置工作空间 |
| `SELECT_AVAILABLE_MODEL` | 选择可用模型 |
| `UPDATE_ARTIFACT_ACCESS` | 更新模型制品权限 |
| `SELECT_AVAILABLE_SPECIFICATION` | 选择可用规格 |
| `REQUEST_QUOTA` | 申请配额 |
| `RETRY_OR_CHANGE_CAPACITY_SCOPE` | 重试或更换地域、规格 |
| `UPDATE_NETWORK_CONFIGURATION` | 更新网络配置 |
| `CONFIGURE_SERVICE_ROLE` | 配置服务角色 |
| `REPAIR_SERVICE_ROLE` | 修复服务角色 |
| `CHANGE_DEPLOYMENT_RESOURCE_NAME` | 修改部署资源名称 |
| `UPDATE_DEPLOYMENT_CONFIGURATION` | 修改部署配置 |

外部跳转目标由部署运行时根据租户、云商、地域和权限解析，不得硬编码带账号信息的控制台URL，也不得向前端下发任意未校验URL。

## 9. 验收边界

1. XCloud 云账号配置和健康接口不出现 `DEPLOYMENT_ADMISSION`、`DEPLOYMENT_READINESS`及部署原因码。
2. Hashrate 只在拥有真实部署上下文后执行准入判断。
3. 无副作用探针只能证明其明确返回的事实，不能承诺消除Create阶段竞态。
4. 技术失败不伪造成权限、配额、容量或网络业务原因。
5. 部署侧代码、枚举和i18n由Hashrate域独立拥有，不能重新放回XCloud云账号模型。
