# schema-to-ui

用于触发“接口结构 / 字段结构 -> 页面骨架与展示方式建议”类任务。

## 适合什么时候用
- 用户提供接口结构、字段结构或简要业务说明。
- 需要先把字段映射成页面结构和区块建议。
- 需要判断页面类型、中间区域布局和组件承接方式。

## 不适合什么时候用
- 已经有明确设计稿，只差前端实现。
- 任务主要是视觉设计或视觉审查。
- 任务主要是修复已有代码 bug。

## 调用前建议先确认
- 当前任务的主工作流是否确实是“结构映射”，而不是实现或审查。
- 输入里是否至少有接口字段、实体关系或业务说明。

## 执行前先读
- `standards/02-布局标准`
- `standards/03-数据映射标准`
- 必要时读取 `standards/04-组件标准`

## 交给执行层时至少应输出
1. 输入摘要与实体范围。
2. 页面类型与结构推断目标。
3. 是否需要补充待确认项。
4. 是否应继续交给 `frontend-implementer` 落实现。

## 交接关系
- 如果输入信息过少，先补待确认项，不要直接硬推实现。
- 如果结构方案已经清楚，再交给 `frontend-implementer`。

不要在这个 command 文件里承载完整执行协议。
完整步骤应继续由 skill 与 rule 承担。
