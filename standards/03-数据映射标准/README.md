# 数据映射标准

## 这一层解决什么问题
这里回答的是：
- 某个字段属于什么语义类型
- 它应该映射成什么展示形式
- 它应该由什么组件承接
- 它需要什么兜底和异常态

它是后端数据结构和前端 UI 之间的桥梁。

## 先看什么
第一次阅读建议按顺序看：
1. [字段分类.yaml](./字段分类.yaml)
2. [高频字段映射.yaml](./高频字段映射.yaml)
3. [按数据类型展示映射.yaml](./按数据类型展示映射.yaml)
