# 页面类型模板

## 列表页
推荐结构：
1. 顶部操作栏
页面标题、筛选入口、主操作按钮
2. 筛选区
搜索框、筛选条件、批量筛选入口
3. 主内容区
表格或卡片列表，必须覆盖空态
4. 底部分页区

适用要求：
- 表头或筛选区在长列表中应具备稳定的定位方式
- 数据行应提供明确的 hover 和选中反馈

## 详情页
推荐结构：
1. 顶部导航和主操作
2. 基本信息区
3. 右侧补充信息区或辅助区
4. 子列表 / Tab / 日志 / 时间线区

适用要求：
- 主要状态和主要操作应靠近标题区
- 左右分栏与单列结构应由信息密度决定

## 表单页
推荐结构：
1. 顶部标题与返回
2. 可选步骤指示器
3. 居中的主表单区
4. 右对齐的提交区

适用要求：
- 表单主区域宽度应稳定
- 校验提示应靠近字段
- 操作区位置应稳定，不随内容抖动
