# 布局标准

## 这一层解决什么问题
这里回答的是：
- 面对某类业务结构，页面骨架怎么选
- 中间区域怎么拆成哪些区块
- 列表、详情、表单分别该怎么组织
- 哪些展示形式适合当前数据密度和任务目标

它负责“页面结构与信息层次”，不负责颜色字体，也不负责组件内部实现。
