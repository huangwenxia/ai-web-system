# 交互语义与状态完整性

## 交互语义
- Hover / Active / Focus 只应出现在可交互元素上
- 展示型组件不应有 hover 效果和 pointer 光标
- 可交互卡片需要明确的 `cursor-pointer` 和状态反馈
- 禁用状态必须同时具备视觉弱化和交互禁止，例如 `opacity: 0.4 - 0.5` + `cursor-not-allowed`

## 组件状态完整性
每个交互组件必须明确审查以下状态：
- Default
- Hover
- Active / Pressed
- Focus
- Disabled
- Error / Invalid
- Loading
- Empty

## 骨架屏视觉规范
- 骨架屏颜色应使用浅层 token
- 骨架屏间距遵循 4px 基准网格
- 骨架屏高度、圆角、布局应与真实内容保持一致
- 骨架屏优先用于防止高度塌缩和 CLS
- 当加载前该区域会高度塌缩时，应优先使用骨架屏而不是单纯 spinner
- 骨架屏组件命名应清晰且与真实内容组件配对
