# 视觉节奏与信息组织

## 信息组织
- Key 和 Value 必须视觉分离，不能拼成一个字符串
- 当上下文已足够清晰时，可只展示 value，省略 key
- 详情页、表单和需读屏的结构化信息中，应保留 key
- 同类列表中的对齐方式必须统一

## 视觉层级节奏
- 同一区域相邻层级的尺寸差值不宜过大
- 相邻层级元素高度比建议控制在 `1.5:1` 以内
- 信息密集型容器内边距优先 `12 - 16px`
- 宽松型容器内边距优先 `20 - 24px`

## 卡片内部间距层级
- 卡片外边距应大于内部 item 间距
- 区块与区块之间优先 `16px`
- section 标题到内容优先 `8 - 12px`
- item 内 icon 到文字优先 `8 - 12px`
- label 到值优先 `4 - 8px`

## 视觉权重分配
- 辅助元素的视觉权重不得超过所属区域的主要内容
- 颜色用于分类，不用于序数
- 标签、徽标、角标不得打断主要扫描路径

- `ui.md` -> 卡片内部间距层级规范
- `ui.md` -> 视觉权重分配与注意力竞争
