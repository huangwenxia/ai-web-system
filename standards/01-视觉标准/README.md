# 视觉标准

## 这一层解决什么问题
这里回答的是：
- 页面看起来是否合格
- 视觉层级是否清晰
- 间距、字体、颜色、卡片、状态、对齐是否稳定

它负责“视觉判断标准”，不负责页面业务结构和组件 API。
