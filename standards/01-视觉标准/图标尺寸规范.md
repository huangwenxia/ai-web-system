# 图标尺寸规范

## 核心规则
- 图标尺寸必须基于固定比例，禁止随意设置
- 使用 Tailwind 的 `w-*` / `h-*` 类，或项目定义的 size token
- 图标颜色必须使用 CSS 变量或 Tailwind 的 text color 类

## 图标尺寸基准（锁定）

| Token | 值 | 场景 |
|-------|----|------|
| `w-3 h-3` / `w-3.5 h-3.5` | 12-14px | 行内伴随文字 |
| `w-4 h-4` / `w-3.5 h-3.5` | 14-16px | 表格操作列、表单内嵌 |
| `w-5 h-5` | 20px | TopBar 按钮、工具栏 |
| `w-6 h-6` | 24px | 页面标题区 |
| `w-10 h-10` | 40px | 空状态插画 |
| `w-12 h-12` | 48px | 模型 Logo（列表行） |

## 常用图标场景对照

| 场景 | 推荐尺寸 |
|------|---------|
| 按钮内嵌图标 | `w-4 h-4` 或 `w-5 h-5` |
| 输入框前缀/后缀 | `w-4 h-4` |
| 表格操作列 | `w-4 h-4` |
| 标签/表单左侧图标 | `w-4 h-4` |
| 空状态插画 | `w-10 h-10` 或 `w-12 h-12` |
| 卡片顶部图标 | `w-6 h-6` |
| Sidebar 导航项 | `w-5 h-5` |

## 禁止
- 硬编码 `width: 14px` 而非 Tailwind 类
- 图标与文字间距不匹配（文字 14px + 图标 20px 显得拥挤）
- 图标单独使用，不考虑与相邻文字的垂直居中对齐
