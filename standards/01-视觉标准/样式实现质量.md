# 样式实现质量

## 布局实现
- 优先使用 Flex / Grid 布局
- 元素右对齐优先使用 `margin-left: auto`
- 绝对定位只用于浮层、角标、固定悬浮按钮等明确场景
- 内联 style 能用 class 替代时必须替代

## 宽度与常量
- 布局宽度常量不应内联在 Tailwind 类中，应提取到 scoped CSS 或 token

## 过渡与动画
- 禁止 `transition-all`
- 必须显式指定过渡属性

## 图标与渐变文字
- 禁止在组件内写内联 SVG
- 图标优先使用设计系统和项目统一来源
- 优先级通常为：设计系统内置图标 > 项目统一 iconfont > 业务定制图标组件
- 对 `el-icon` 之类依赖 `color` 继承的组件，应优先使用组件提供的 `color` 能力，而不是用通用文本类碰运气
- `background-clip: text` 必须写入 CSS 类中，不能直接内联

## 其他实现规则
- 同一属性不重复声明
- 魔法数值应提取为 token 或 CSS 变量
- 响应式断点必须从默认状态向上覆盖
