# 多卡片等高实现模式

## 三层协作模式
多卡片等高应通过三层协作实现，而不是依赖魔法高度值：

1. 父容器
- 使用 `items-stretch` 或 CSS Grid 行内等高能力

2. 卡片容器
- 使用 `flex flex-col`

3. 可变高度区
- 使用 `flex-1`
- 必要时配合 `min-h-0`
- 文本过长时使用 `line-clamp`

## 关键规则
- `min-h-0` 是 flex 子项在可收缩场景下的必要条件
- 截断文本必须提供信息兜底
- 外层卡片等高与内层字段行对齐是两个不同问题，应分开处理
