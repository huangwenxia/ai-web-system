# Visual Language

## Goal
Define the visual quality baseline for project UI output.

## Required
- Primary information must be visually dominant over metadata and helper text.
- Color must support hierarchy, not replace it.
- Status and semantic tags must not compete with core business values.
- Repeated surfaces must follow a stable radius, spacing, and border rhythm.

## Recommended
- Prefer restrained emphasis before using strong contrast.
- Keep one dominant visual accent per block.
- Use spacing and typography before adding decorative elements.

## To Refine From Real Cases
- What counts as primary information in list cards
- Summary card visual weight rules
- Badge and tag attention limits
