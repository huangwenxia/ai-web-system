# 视觉语言总则

## 这份总则定义什么
这份文档定义的不是组件怎么写，而是产品应该“看起来像什么”。

AI Web System 的视觉语言本质上是一套面向判断与操作的界面语言，不是展示型海报语言，也不是情绪型消费产品语言。它首先要让用户快速理解当前页面在做什么、重点在哪里、哪里可以操作、哪里需要谨慎；其次才是品牌识别与审美完成度。

具体颜色、字体、间距、图标、动效和状态规则，分别在对应专题文档中展开；本页只定义最上层的视觉立场。

## 产品视觉人格
- 理性，但不冷漠。
- 专业，但不僵硬。
- 克制，但不贫瘠。
- 稳定，但不沉闷。

这套视觉语言应当给人的感受是“可判断、可操作、可信任”。它更像专业控制台和工作台，而不是营销页、内容社区或娱乐产品。品牌感不来自装饰堆叠，而来自稳定的框架、明确的层级和少量但准确的强调。

## 视觉结构模型
基于 `agione-ui-skill` 的设计哲学，整个系统采用双层视觉结构：

- 品牌框架层：负责身份识别与全局稳定性，包括 TopBar、Sidebar、语言切换、主题切换等共享 chrome。
- 内容工作层：负责承载任务本身，包括列表、表单、详情、概览、向导等页面内容。

总原则是：品牌框架必须稳定，内容表达可以灵活；先让用户认出这是同一个产品，再让用户进入当前任务。

## 页面叙事原则
- 一个页面只能有一个主叙事，不能同时让“管理、总览、创建、分析”并列为中心。
- 页面进入后的第一扫描路径应稳定：标题与主操作 -> 当前对象或核心数据 -> 状态与筛选 -> 补充说明。
- 页面结构优先通过分区、留白和对齐建立理解，不靠颜色堆叠制造层级。
- 概览页先给判断，再给动作，再给趋势与明细。
- 表单页先给上下文，再给输入，再给提交与风险提示。
- 详情页先给对象身份，再给属性、关系和历史。

## 视觉权重原则
- 页面标题和主操作应清晰，但不应压过真正的业务核心内容。
- 核心对象名称、关键数据、当前状态必须在最短扫描路径中被识别出来。
- 标签、Badge、角标、辅助文案只承担注释职责，不能成为页面主角。
- 边框、底色、分隔线只用于组织关系，不能被当作装饰元素使用。
- 同一区块只允许一个主强调点；如果有第二强调点，必须通过位置或层级降权，避免竞争。

## 形式语言
- 造型应清晰、收束、可控，避免过度可爱、过度圆润或过度锋利。
- 界面表面应以干净底面、克制边界和轻量阴影建立秩序，不依赖复杂纹理和装饰。
- 留白是第一组织工具，分隔线是第二组织工具，颜色是第三组织工具。
- 品牌色只应用于激活态、主操作、关键状态和有限的品牌识别，不应用于大面积铺陈。
- 明暗主题必须表达同一种产品人格，不能像两套不同审美的产品。

## 排版与双语原则
- 标题要有判断力，正文要有耐读性，数据要有工具感。
- 中文与英文是并列语言，不允许一方像“主语言”、另一方像“注释语言”。
- 中英切换后，版面节奏和主次关系应保持稳定，不能因为文案长度变化破坏层级。
- 数字、时间、ID、金额等信息应具备明显的数据感和对齐感，区别于普通叙述文字。

## 交互气质
- 交互反馈应当“快但不躁”，帮助用户确认状态变化，而不是制造表演感。
- Hover、Focus、Active 的作用是降低操作犹豫，不是增加热闹感。
- 危险操作必须视觉审慎，与普通操作区分语气、颜色和确认方式。
- 空状态、加载态、错误态不能只说明系统状态，还必须告诉用户下一步怎么做。
- 任何状态反馈都不能只靠颜色区分，必须同时具备文字或图形语义。

## 典型页面气质
- 列表页应像控制面板：高效、整齐、可快速扫描。
- 表单页应像工作台面：边界清晰、输入稳定、错误就近出现。
- 详情页应像档案阅读器：对象身份清楚，信息分组自然，关系链可追踪。
- Dashboard 应像态势总览：先给全局判断，再给关键动作，再展开趋势和明细。
- 向导页应像陪同决策：路径清楚、进度可见、上下文不丢失。

## 一致性底线
- 共享 chrome 不是页面自由发挥区，而是品牌识别区。
- 任何新页面都必须延续既有的品牌框架、阅读节奏和注意力分配方式。
- Light / Dark、中文 / 英文、表格 / 卡片、桌面 / 响应式，只能改变适配方式，不能改变产品气质。
- 实现层可以演进，视觉人格不能漂移。

## 反模式
- 把每个模块都做成“重点”，导致页面没有真正的中心。
- 用颜色替代层级，让高饱和标签、状态块和按钮同时争抢注意力。
- 把 Badge、Tag、角标做得比对象名称和核心数据更显眼。
- 让 TopBar、Sidebar 等共享 chrome 随页面风格自由漂移。
- 把深色模式做成另一套完全不同的审美语言。
- 为了“有设计感”加入夸张动效、复杂背景或无意义装饰。

## 审查时先问的几个问题
- 用户是否能在 3 秒内看出这页的主任务是什么。
- 页面是否存在唯一明确的视觉中心。
- 共享 chrome 是否仍然稳定地代表同一个产品。
- 标签、状态、辅助说明是否压过了真正重要的内容。
- 中英切换、明暗切换后，这个页面是否仍然成立。
