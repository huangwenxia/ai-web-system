# 动效规范

## 核心规则
- 动效时长必须基于固定比例，禁止随意设置
- 动效用于反馈和过渡，不用于装饰
- 优先使用 CSS transition，不滥用 animation

## 动效时长基准（锁定）

| Token | 值 | 场景 |
|-------|----|------|
| `--duration-fast` | 150ms | hover / focus / state 变化 |
| `--duration-base` | 250ms | card hover / tooltip 出现 |
| `--duration-slow` | 400ms | drawer / dialog 进出 |

## 缓动函数

| 场景 | 缓动 |
|------|------|
| 常规过渡 | `cubic-bezier(0.4, 0, 0.2, 1)` 或 `ease-out` |
| 强调进入 | `cubic-bezier(0, 0, 0.2, 1)` 或 `ease-in` |
| 弹性效果 | 仅用于成功反馈，不用于常规交互 |

## 审查信号
- 动效时长超过 400ms（感觉迟钝）
- hover 时做 scale / translate 位移（应只用颜色/阴影）
- loading 状态用 animation 而非 spinner
- 页面切换有过渡动画拖慢感知速度

## 禁止
- 动效用于装饰（飘落、闪烁等）
- hover 时元素位移（只能用颜色/阴影变化）
- 页面主体内容区域的 entrance animation
