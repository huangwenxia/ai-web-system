# 卡片网格高度策略

## 核心规则
同一网格中的卡片必须保持统一的扫描节奏。
是否强制等高，不取决于“看起来像卡片”，而取决于卡片的内容角色。

## 商品型卡片
满足以下任意两项，可判定为商品型卡片，应强制等高：
- 卡片点击后跳转详情页，真正内容在卡片外
- 有结构化元数据字段，例如 tag、badge、数量、价格
- 用户动作是“比较 -> 选择”，不是“浏览 -> 阅读”
- 多列网格布局为主
- 代码或路由语义接近 `store / list / market / catalog / item / card`

### 对应策略
- 各内容区设置固定高度上限
- 描述区使用固定高度加 `line-clamp-N`
- 行高和截断行数必须匹配
- 截断内容必须提供信息兜底，例如 `title`、Tooltip 或详情页

## 内容型卡片
满足以下任意两项，可判定为内容型卡片，可不采用固定截断式等高：
- 描述文字是卡片主要信息，不是辅助说明
- 内容长度差异本身对用户判断有价值
- 用户动作是“阅读 -> 发现”
- 单列或两列布局为主
- 代码或路由语义接近 `feed / news / blog / post / article / activity`

### 对应策略
- 父容器优先使用 CSS Grid
- 由同一行中最高卡片撑起行高
- 卡片内部的可变高度区使用 `flex-1`
- 底部操作栏保持落底对齐

## 模糊判断原则
截断描述后，如果用户的核心决策不受影响，则更接近商品型；
如果受影响，则更接近内容型。
