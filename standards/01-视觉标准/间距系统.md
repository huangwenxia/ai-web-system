# 间距系统

## 核心规则
- 所有间距必须基于 4px 基准网格，优先使用 `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px`
- 禁止使用魔法数值，例如 `-2px / 3px / 7px`
- 负边距用于修正对齐是反模式，应从源头修正容器 `padding` / `gap`
- 伪元素的定位值如果与父容器的 `gap` / `padding` 存在数学依赖关系，必须显式对应
- 不允许通过 `margin-top: -Xpx` 掩盖布局系统失衡

## 审查信号
- 出现与布局系统无关的单独偏移值
- 同类卡片内边距和区块间距不一致
- 用负 margin 修补局部对齐
