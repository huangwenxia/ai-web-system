# 间距系统

## 核心规则
- 所有间距必须基于 Tailwind 的 4px 基准网格
- 直接使用 Tailwind spacing 类（如 `p-4`, `gap-4`, `space-x-4`）
- 优先使用 Tailwind 语义化类名，不自行创建魔法数值

## Tailwind Spacing 基准（锁定）

| Tailwind | 值 | 场景 |
|----------|----|------|
| `p-1` / `m-1` | 4px | 图标与文字间距、紧凑内边距 |
| `p-2` / `m-2` | 8px | 行内元素间距、组件 gap |
| `p-3` / `m-3` | 12px | 组件内边距（紧凑）、按钮组 gap |
| `p-4` / `m-4` | 16px | 表格列内边距、表单行间距 |
| `p-5` / `m-5` | 20px | 卡片内边距 |
| `p-6` / `m-6` | 24px | 主内容区内边距、Section 间距 |
| `p-8` / `m-8` | 32px | 大区块间距 |
| `p-12` / `m-12` | 48px | 页面顶部空白 |

禁止：
- 魔法数值如 `ml-[-2px]`
- 自行创建不在 Tailwind 网格内的间距

## 审查信号
- 出现 Tailwind 网格外的魔法数值
- 同类卡片内边距和区块间距不一致
- 用负 margin 修补局部对齐

## 对应来源
- Tailwind CSS 默认 spacing 比例
- `ui.md` -> 间距系统
