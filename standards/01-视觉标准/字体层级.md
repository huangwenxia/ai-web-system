# 字体层级

## 核心规则
- 同一页面最多使用 3 个字重层级，常见组合为 `Bold / Medium / Regular`
- 标题与描述文字不能使用相同字重
- 标题 `line-height` 建议 `1.2 - 1.4`，正文 `line-height` 建议 `1.5 - 1.7`
- 不使用默认 `line-height: 1`
- 直接使用 Tailwind 的 font size 类，不自行设置 `font-size: 14px`

## Tailwind Font Size 基准（锁定）

| Tailwind | 字号 | 字重 | 行高 | 用途 |
|----------|------|------|------|------|
| `text-2xl` | 30px | 800 | 1.2 | 页面主标题 |
| `text-xl` | 20px | 700 | 1.4 | Section 标题 |
| `text-base` | 16px | 600 | 1.4 | 卡片标题、弹窗标题 |
| `text-sm` | 14px | 400 | 1.6 | 正文、标准段落 |
| `text-xs` | 12px | 500 | 1.33 | 标签、辅助说明、错误提示 |
| `font-mono` | 11-16px | 400 | — | 数字、时间、ID、代码（右对齐） |

注意：Tailwind 的 `text-sm` 默认是 14px，设计师可能用 13px，需确认设计稿后选用。

## 审查目标
- 标题、次标题、正文、辅助信息在视觉上层级明确
- 不让描述文字与主要数据抢权重
- 不混用非 Tailwind 的字号
