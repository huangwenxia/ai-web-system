# First Pass Plan

## Goal
Build the first usable version of the standards library from real project assets.

## Step 1
Pick 3 existing components with high reuse and business value.

## Step 2
For each component:
- generate usage documentation
- identify API and state coverage issues
- extract reusable rules

## Step 3
Pick 2 representative pages:
- one list page
- one detail or form page

## Step 4
Extract:
- layout patterns
- field-to-component mappings
- review checklist items

## Step 5
Use the new standards on one new implementation task and one review task.
