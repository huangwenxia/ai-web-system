# 标准库地图

## 一句话定位
这套库是“直接给人和模型使用的标准本体”，不是入口层，不是提示词层，不是单次任务记录层。

## 分层地图
### 01-视觉标准
存“怎么判断界面质量”。
包括颜色、间距、字体、密度、状态、卡片、对齐、骨架屏、视觉权重。

### 02-布局标准
存“页面和中间区域怎么组织”。
包括页面信息层次、展示形式选择、页面模板、结构复用、业务约束推断。

### 03-数据映射标准
存“字段怎么映射成 UI”。
包括字段分类、枚举规则、展示映射、字段优先级。

### 04-组件标准
存“组件怎么设计和审查”。
包括 API、状态与数据流、模板边界、质量基线、表格列规则、组件模板。

### 05-文档标准
存“文档和审查怎么产出”。
包括组件文档模板、审查规则、验收清单、自动生成规则、编码基线。

### 06-治理机制
存“标准如何产生和维护”。
包括角色与职责、准则维护原则、证据来源分级、准则新增流程、变更记录。

### 07-任务记录
存“这次做了什么”，不是“规则本体是什么”。

## 与 Skill / commands 的关系
- 标准本体在这里
- Skill / commands 可以存在
- 但它们只能读取这里，不能再成为第二主库
