## 这套库解决什么问题

它不是普通文档集合，也不是组件代码仓。它是一套“UI 决策标准库”，用来统一：

- 审美判断
- 页面结构判断
- 字段到 UI 的映射判断
- 组件设计与审查判断
- 标准治理与升级判断
