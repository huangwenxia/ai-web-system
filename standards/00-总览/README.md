## 这套库解决什么问题
它不是普通文档集合，也不是组件代码仓。
它是一个“UI 决策标准库”，用来统一：
- 审美判断
- 页面结构判断
- 字段到 UI 的映射判断
- 组件设计与审查判断
- 文档和验收判断

## 目录说明
- `01-视觉标准`
  回答“界面看起来是否合格，为什么合格”。
- `02-布局标准`
  回答“面对某类业务结构，页面骨架和中间区域怎么组织”。
- `03-数据映射标准`
  回答“字段属于什么类型，应该映射成什么展示形式和组件”。
- `04-组件标准`
  回答“组件应该怎么设计、怎么审查、怎么复用”。
- `05-文档标准`
  回答“组件文档、审查报告、验收清单怎么产出”。
- `06-治理机制`
  回答“标准凭什么成立、谁来维护、怎么更新”。
- `07-任务记录`
  存协作过程，不是标准本体。

## 当前使用方式
标准本体直接维护在 `ai-web-standards`。
后续如果保留 Skill / commands，它们只能是读取本库的工作流入口，不能重新定义规则。
