# 如何使用标准库

## 日常协作
你和 Codex 的协作，长期固定为五类任务：

1. 解读已有组件
输出职责、输入输出、适用场景、反模式，并沉淀到 `04-组件标准`

2. 审查已有页面或组件
按标准库输出问题、影响、优化建议，并回写规则

3. 从接口或类型推 UI
读取 `02-布局标准` 和 `03-数据映射标准`，给出页面结构和中间区域方案

4. 沉淀标准条目
把反复出现的问题沉淀到对应标准目录

5. 生成新组件
基于已有标准生成组件代码、文档和验收清单

## 阅读顺序
### 当你要审美判断时
先看：
- `01-视觉标准`
- 必要时再看 `02-布局标准`

### 当你要决定页面结构时
先看：
- `02-布局标准`
- `03-数据映射标准`

### 当你要做组件设计或代码审查时
先看：
- `04-组件标准`
- `05-文档标准`
- 必要时补看 `01-视觉标准`

## 更新原则
- 规则先有来源，再入库
- 先判断属于哪一层，再决定写到哪个目录
- 任务流程不写进标准本体
- 单次例外不直接升级为正式规则
