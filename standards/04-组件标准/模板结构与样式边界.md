# 模板结构与样式边界

## 模板结构
- 模板负责声明结构，复杂判断应移到 `computed` 或方法
- 稳定列表禁止使用数组索引作为长期 `key`
- 点击区域必须使用语义化可交互元素
- 模板内出现复杂条件组合时，应抽成命名 `computed`

## 样式边界
- 样式只描述当前组件，不污染外层
- 通用组件不写页面级样式分支
- 无理由禁止新增裸十六进制颜色、魔法间距、魔法高度
- 在当前项目已使用 Tailwind CSS 的前提下，组件和页面样式默认优先使用项目现有 Tailwind 工具类完成
- 除必要的动态背景、运行时计算样式或 Tailwind 无法稳定表达的特殊样式外，不建议额外拆分独立样式文件或大段 scoped 样式
- 如果必须写额外样式，应先说明为什么现有 Tailwind 工具类不足以表达，并将样式范围严格限制在当前组件
- 类名应表达结构或语义，不表达一次性视觉补丁

## 复用与维护
- 重复逻辑抽 composable / utils
- 共性样式沉淀到组件、变量或工具类
