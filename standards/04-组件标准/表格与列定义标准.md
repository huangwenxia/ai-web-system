# 表格与列定义标准

## 状态与枚举列
- 在统一表格体系中，状态和枚举列优先使用字典列工厂
- 禁止手动通过自定义渲染重复实现统一状态组件
- 如果表格系统已支持 `options` 驱动渲染，应走框架约定，而不是手动 `h(Component)`

## 列定义规则
- 普通文本列使用普通列工厂
- 日期时间列使用日期列工厂
- 模板插值只用于明确的组合展示
- 自定义渲染仅在已有列工厂无法满足时使用

## 列能力
- 长文本列应具备溢出省略和 tooltip
- 宽度、最小宽度、固定列、排序、隐藏等能力应优先通过链式 API 或统一配置表达

## 目标
- 保持表格列定义一致
- 避免手写 formatter 带来的状态组件参数错误
- 让枚举和状态展示统一走同一标准
