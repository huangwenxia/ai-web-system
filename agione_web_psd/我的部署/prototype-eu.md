## 1. 原型目标

验证 `eu` 角色在“模型固定 -> 参数筛选 -> 推荐方案 -> 确认部署”这条主链路下，是否能够：

- 快速理解“先选模型、再做部署推荐”的页面节奏
- 在有限步骤内完成部署模式、推理引擎、云服务商与算力条件的组织
- 从右侧推荐方案中快速选定一个候选结果
- 在确认页无重复理解成本地完成账号选择和部署提交

## 2. 角色与视角

本次原型仅覆盖一个业务身份角色：`eu`

说明：

- 本 REQ 当前仅确认 `eu` 角色参与原型设计

## 4. 页面清单与字段定义

### 4.1 模型广场

**页面目标**：让用户先完成“模型选择与固定”，再进入后续部署推荐。  
**页面类型**：`选择页 / 展示页`  
**可见角色**：`eu`

#### 已确认页面定位

- 页面定位：部署推荐前的独立入口页，不与部署参数混排
- 页面布局：左侧模型卡片列表，右侧当前已选模型摘要与说明
- 顶部 Banner：强提示“当前已选模型”
- 过滤方式：`搜索框 + 固定分类导航`
- 分类导航形态：水平固定导航，不使用下拉
- 分类项：`全部模型 / Qwen / DeepSeek / Meta / Google / ChatGPT`
- 分类导航需展示计数徽标
- 列表展示方式：卡片网格
- 分页方式：分页切换，当前按 `3` 张卡片一页
- 卡片需优先使用真实模型 Logo；没有 Logo 时允许回退到图形占位
- 当前已接入的模型样例：`Qwen3-8B / Qwen3-32B / DeepSeek-R1 Distill 32B / Llama 3.1 70B / Qwen Coder 14B / Gemma 2 27B`
- 模型卡片字段顺序：
  - `模型 Logo`
  - `模型名称`
  - `适配定位`
  - `标签`
  - `描述`
  - `参数规模 / 上下文 / 推荐显存`
  - `进入部署引导`
- 右侧摘要卡字段：`参数规模 / 上下文 / 推荐显存 / 推荐引擎`
- 右侧辅助说明块：`部署视角` + `推荐规则`
- 清空动作：同时清空搜索关键词、分类筛选和当前分页

#### 已确认布局骨架

1. `PageHeader`
2. `当前已选模型 Banner`
3. `左侧模型广场卡片区`
4. `右侧当前模型摘要卡`
5. `右侧说明卡（部署视角 / 推荐规则）`

#### 已确认核心功能

1. 搜索模型名称、标签或描述
2. 点击固定分类导航筛选模型
3. 翻页浏览模型列表
4. 选中一个模型
5. 点击 `进入部署引导`
6. 从模型广场重新选模型时，允许覆盖当前模型

说明：

- `ChatGPT` 分类入口当前保留为分类壳，不要求必须有完整样例模型
- 模型重新选择后，将在下游阶段触发状态清空

### 4.2 部署引导

**页面目标**：让用户围绕已固定模型组织部署条件，并从右侧推荐方案中选定一个目标候选。  
**页面类型**：`工作台 / 左右分栏页`  
**可见角色**：`eu`

#### 已确认页面定位

- 页面定位：部署推荐的主决策页
- 布局方向：左侧 `选择业务参数`，右侧 `模型部署方案`
- 顶部固定模型 Banner：展示当前模型与核心标签，允许返回重新选模型
- 左侧参数区为纵向步骤流
- 右侧方案区不按“策略分组”拆块，统一展示当前条件下最值得比较的 `Top 3`
- 预算倾向不单独做策略分区，而是直接影响右侧推荐置顶顺序
- 方案卡直接承接 `选中方案` / `确认并部署`
- 本版不再设计独立比较 Drawer，也不做“加入比较”分支

#### 已确认步骤字段

| 步骤 | 字段名 | 控件形态 | 已确认选项 / 说明 |
| --- | --- | --- | --- |
| 1 | 部署模式 | 二选一 Pill | `单节点` / `高可用` |
| 2 | 推理引擎 | 单选 Pill | `vLLM / SGLang / TGI / TensorRT-LLM` |
| 3 | 云服务商 | Logo 卡片 | `阿里云 / 华为云 / AWS / Google Cloud`，卡片内展示 Logo、名称、可用账号数 |
| 4 | 芯片/算力型号 | 多选 Pill | `NVIDIA V100 / A100 / H200` |
| 5 | 显存配置 | 预设 + 自定义范围 | `24GB 起 / 48GB 起 / 80GB 起 / 自定义`，支持最小/最大显存输入 |
| 6 | 预算倾向 | 带说明的单选卡片 | 见下表 |

#### 已确认“预算倾向”选项

| 选项 | 说明 |
| --- | --- |
| 经济适用 | 追求绝对的低价、高性价比 |
| 卓越性能 | 不看价格，只要最好的硬件和性能 |
| 价格限额 | 严格控制单价上限，超过就过滤掉 |
| 现货速达 | 哪个有空闲资源、能秒级启动就选哪个 |

步骤 6 的辅助说明固定为：

`设定最终算力账单的过滤权重。右侧方案将根据您的预算偏好进行置顶推荐。`

#### 已确认右侧方案卡内容

- 标题：`云服务商 + 地域`
- 第二行：`推理引擎版本 / GPU 型号 / 部署模式`
- 价格主信息：`¥ / 小时` + `$ / hour`
- 右上角 Badge：`推理引擎` + `部署模式` + `Top 排名`
- 指标区字段：
  - `云服务商`
  - `地域`
  - `部署模式`
  - `推理引擎`
  - `GPU`
- 适配说明：一段简短推荐理由
- 底部动作：`选中方案` + `确认并部署`

#### 已确认布局骨架

1. `PageHeader`
2. `当前模型已固定 Banner`
3. `左侧选择业务参数卡片`
4. `右侧模型部署方案卡片`

#### 已确认核心功能

1. 展示当前已固定模型
2. 按 6 步组织部署条件
3. 点击 `生成部署方案`
4. 右侧仅展示当前范围内最值得比较的 `3` 套方案
5. 选中目标方案
6. 从某张方案卡直接进入确认页
7. 修改模型后，清空推荐结果、已选方案和部署草稿

说明：

- 默认推荐模式下，右侧最多保留 `Top 3`
- `部署模式` 已参与真实筛选，不是纯展示字段

### 4.3 确认与部署

**页面目标**：让用户基于已选推荐方案完成确认、选择云账号并发起部署。  
**页面类型**：`确认页 / 表单页`  
**可见角色**：`eu`

#### 已确认页面定位

- 页面定位：主流程最后一步，只承接已选方案，不重新做推荐决策
- 布局方向：左侧 `已选模型部署方案` 摘要，右侧 `部署信息` 表单
- 进入方式：从 `部署引导` 中带入已选方案
- 无已选方案时：显示空状态页，不展示表单

#### 已确认摘要区字段

- `模型`
- `部署云商`
- `地域`
- `部署模式`
- `推理引擎`
- `GPU`
- `价格偏好`

摘要区底部辅助信息：

- `推理引擎 Badge`
- `双币价格`
- `交付说明`

#### 已确认表单字段

| 字段 | 控件形态 | 说明 |
| --- | --- | --- |
| 云账号 | `Select` | 按已选方案对应云商自动过滤 |
| 任务名称 | `Input` | 必填；默认自动带入模型名和引擎 |
| 任务描述 | 折叠式 `Textarea` | 本期选填，默认收起 |

#### 已确认动作与反馈

- 主动作：`发起部署`
- 次动作：`返回部署引导`
- 提交反馈：`Toast`
- 提交中状态：仅 `发起部署` 按钮进入 loading
- 部署成功后：默认跳转任务列表页
- 部署失败后：停留当前页，保留已填信息，可继续重试

#### 已确认布局骨架

1. `PageHeader`
2. `空状态 / 已选方案摘要区`
3. `部署信息表单区`
4. `底部操作区`

## 7. 页面状态要求

| 页面 | 空状态文案 | 加载态方式 | 错误态处理 |
| --- | --- | --- | --- |
| 模型广场 | `没有匹配的模型` | 无需独立全页 loading | 清空搜索或切回全部分类 |
| 部署引导 | `当前没有可推荐方案` | 右侧方案区刷新 | 保留左侧筛选条件，允许继续调整 |
| 确认与部署 | `还没有选中部署方案` | 仅提交按钮 loading | 失败采用 `Toast`，保留表单内容 |

补充说明：

- 确认页若当前云商下无可用账号，表单保留，但账号下方显示 Warning
- 修改模型后，必须清空推荐结果、已选方案和部署草稿

## 9. 设计约束与评审关注点

### 9.1 设计约束

- 必须保持三阶段强分段：`模型广场 -> 部署引导 -> 确认与部署`
- 模型选择必须是前置独立动作，不能回到同页里与部署条件混排
- 模型一旦变化，必须清空下游推荐结果与部署草稿
- 右侧推荐方案最多保留 `3` 个
- 预算倾向要直接影响推荐置顶，不再拆成独立策略分组
- 当前版本不引入单独比较 Drawer

### 9.2 评审关注点

1. 模型广场是否足够像“选择模型入口”，而不是技术配置页
2. 六步参数组织是否足够清晰，是否符合用户理解顺序
3. 预算倾向四个选项是否易懂、易比较
4. 右侧推荐方案卡是否在不展开详情的情况下就能支持决策
5. 确认页是否足够短链路、低重复输入
